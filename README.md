# Fatima Alawad - C# Portfolio

Welcome to my personal portfolio! This repository showcases the C# and .NET projects I have completed during my course.

## Projects

### Car Insurance
This project is an MVC web application that mimics a car insurance website. 
It takes user input on policy information and calculates a quote based on business logic. 
There is also an admin page that allows staff to view all of the quotes that have been issued.

### NFL Stats
This is a data visualization application that is meant to store and display football stats for fantasy football purposes. 
It is an MVC web application that utilizes Entity Framework 6 for data access and a Code First workflow. 
It is still a work in progress.

### Console App - Student Database (Code First)
This is a console application demonstrating Entity Framework Code First. 
It creates a Student database and adds a static student record. 
It shows how to use DbContext, models, and database initialization in C#.
